# Hard constraint: this is not Nello-Deakin (2022)

Nello-Deakin, S. (2022). Exploring traffic evaporation: Findings from tactical urbanism interventions in Barcelona. *Case Studies on Transport Policy*, 10, 2430–2442. https://doi.org/10.1016/j.cstp.2022.11.003

Paper 1 **must not** be a second version of that article. If a design choice would make a CSTP reviewer say “this is the same study with more years,” it is out.

## What that paper already did

| Element | Nello-Deakin 2022 |
|---|---|
| Question | Did traffic evaporate after tactical road-space cuts? |
| Treatment | 11 Eixample streets, May 2020–March 2021 (COVID tactical urbanism) |
| Data | Public aforament MADT |
| Time | H2 2019 vs H2 2021 |
| Spatial design | Intervention / adjacent parallel / 500 m buffer / rest-of-city control |
| Outcome | Relative change in traffic **volume** (ADT) |
| Finding | About −14.8% on intervention streets vs control; little average adjacent increase |
| VKT | Not measured |
| Network assignment | No |
| Permanence | Tactical, COVID window |

He already answered: on those streets, local traffic fell without one-for-one displacement onto parallel streets, in a COVID-contaminated window, using Euclidean buffers.

## What Paper 1 is forbidden to do

1. Use those 11 streets as the **study**.
2. Repeat intervention / adjacent / 500 m buffer / city control as the main design.
3. Make “does traffic evaporate?” the research question.
4. Report 2019 vs 2021 MADT on the tactical set as the main result (even with 2024–25 bolted on).
5. Treat Sample C (2020 lane cuts) as a “replication with extra years.” That is the same paper.

**Sample C is out of Paper 1.** Cite Nello-Deakin in the literature review as the local-volume result we take as given. Do not re-estimate it.

## What Paper 1 must do instead

| Element | Paper 1 |
|---|---|
| Question | When road space is permanently reallocated, does **network vehicle travel** fall, or is travel redistributed — and over what network distance? |
| Treatment | Eixos Verds phase 1, Aug 2022–spring 2023 (permanent, post-COVID) |
| Contrast with Nello-Deakin | Different intervention, different time, different outcome, different spatial object |
| Spatial design | Distance bins from the **built green axes** (network distance; Euclidean only as a labelled interim) |
| Outcomes | \(\Delta Q\) by distance **and** a bounded \(\Delta VKT_{network}\) from assignment |
| Claim we need | \(LTR \neq NVTR\) |

Same city and same open counters are allowed. Same **research design and sample** are not.

## Overlap we will disclose, not hide

Consell de Cent, Girona and Rocafort had a 2020 tactical cut **and** a 2022–23 permanent rebuild. Nello-Deakin studied the first. We study the second, with 2018–19 vs 2024–25, dropping 2020–23. That overlap is a feature (same streets, new regime) only if the question and metric are different. If we slip back into “ADT fell on Consell de Cent,” we are in his paper.
