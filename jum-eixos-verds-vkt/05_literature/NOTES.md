## How to read the VKT column

| Tag | Meaning |
|---|---|
| none | volume only |
| limited | VKT mentioned, inferred, or local only |
| some_evidence | a VKT-like object (e.g. odometer km) but not assigned network VKT |
| modelled_only | scenario VKT, not measured |
| insufficient | explicit review finding that network VKT is not established |
