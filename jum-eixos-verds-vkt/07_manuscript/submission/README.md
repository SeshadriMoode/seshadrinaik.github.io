# JUM submission pack

This folder is the upload set for *Journal of Urban Mobility*. Empirical claims are unchanged from the working draft; the text is journal voice, sequential tables/figures, and Elsevier declarations.

| File | Role |
|---|---|
| `Moode_JUM_manuscript.md` | Full manuscript (title page through references and figure captions) |
| `Moode_JUM_manuscript.docx` | Word conversion, if generated |
| `Moode_JUM_highlights.txt` | 5 highlights, ≤85 characters each |
| `Moode_JUM_cover_letter.md` | Cover letter for Editorial Manager |
| `Moode_JUM_figure_captions.md` | Captions for EM figure fields |
| `SUBMIT_CHECKLIST.md` | What you still fill (funding, co-authors, APC) |
| `figures/Fig1_….png`–`Fig7_….png` | 300 dpi figures in reading order |

Working lab draft remains `../JUM_paper_draft.md`. Do not upload that file.
